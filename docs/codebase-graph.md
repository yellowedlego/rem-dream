## 1. Quick Navigation for Subagents

Subagents can query relationships across the entire codebase instantly without scanning every file:

### Fast CLI Query Commands
Subagents can run these commands from the repository root:

```powershell
# 1. Summary of core hubs and key communities
npx engram summary

# 2. Inspect a specific symbol, function, or file (shows line numbers, relations, imports/callers)
npx engram explain "MemoryNode"
npx engram explain "src/lib/store.ts"
npx engram explain "src/app/api/chat/route.ts"

# 3. Find the shortest path between any two files or functions
npx engram path "src/app/api/chat/route.ts" "src/lib/store.ts"

# 4. Display dependency tree rooted at a file
npx engram tree "src/lib/types.ts"

# 5. Blast radius / affected execution flows for modified files
npx engram affected-flows "src/lib/store.ts"

# 6. Natural language query across the code graph
npx engram query "where is active persona stored and updated"
```

## 3. Core Libraries & Architecture (`src/lib/`)

```
src/lib/
├── types.ts          # Central domain schemas: MemoryNode, Persona, RemRun, StoryItem, etc.
├── store.ts          # Runtime state & persistence: atomicWriteStore, ensureStore, addNode
├── demo.ts           # Demo / offline sample data generator
├── env.ts            # Environment variables and API keys
├── images.ts         # Image metadata & analysis helpers
├── uploads.ts        # File disk persistence in data/uploads
├── records.ts        # Admin logs and audit trail
├── mail.ts           # Nodemailer transport & email dispatch
├── model/
│   ├── client.ts     # Primary LLM caller (callModelJson, callModelText, telemetry recording)
│   └── mock.ts       # Deterministic mock responses for testing (MODEL_MOCK=1)
├── profile/
│   ├── build.ts      # Builds persona system prompt from memories and traits
│   └── make.ts       # Generates profile from memory insights
├── prompts/
│   ├── profile.ts    # Persona generation and comparison prompt templates
│   ├── safety.ts     # Content safety and moderation system prompt
│   └── story.ts      # Narrative and moment clustering prompts
└── story/
    ├── preprocess.ts # Turn normalization and noise reduction
    ├── split.ts      # Semantic split of dialogue into episodes
    ├── groups.ts     # Moment clustering and constellation grouping
    └── speakers.ts   # Speaker attribution heuristics
```

### Store Hub (`src/lib/store.ts`)
- **Dependents (In-degree > 20):** Almost every API route and server component imports `store.ts`.
- **Key Methods**:
  - `ensureStore()` / `atomicWriteStore()`: Concurrency-safe JSON disk storage.
  - `addNode()`, `deleteNode()`, `getNodes()`: Memory node lifecycle.
  - `addModelCall()`, `getModelCalls()`: LLM telemetry records.
  - `getActivePersona()`, `setActivePersona()`: Current AI persona state.

## 5. Top Hubs ("God Nodes") & Caution Notes

The 5 highest-degree symbols in `rem-dream` are:
1. **`MemoryNode`** (`src/lib/types.ts`):
   - **Degree: 18**. Referenced across 18 separate components and API routes.
   - *Note for agents:* Changing the schema of `MemoryNode` requires updating both frontend renderers (`MeaningSky`, `Exhibit`, `ChatView`) and backend routes.
2. **`store.ts`** (`src/lib/store.ts`):
   - **Degree: 35+**. Foundational state container.
   - *Note for agents:* Modifying file paths or atomic write mechanics directly impacts tests and server-side state.
3. **`client.ts`** (`src/lib/model/client.ts`):
   - Handles all external LLM calls. Emits `ModelCall` records into telemetry.
4. **`api.ts`** (`src/components/api.ts`):
   - Client-side fetcher bridging frontend React components with Next.js App Router endpoints.
5. **`Exhibit.tsx` & `ChatView.tsx`**:
   - Primary user interaction surfaces.

```powershell

npx engram studio export docs/studio
```
